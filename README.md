# Banking
Project Title: Banking Analytics & Financial Performance Dashboard

Project Description:

Analyzed banking transaction data using SQL, Microsoft Excel, and Power BI to evaluate financial performance, monitor debit and credit transactions, identify transaction trends, and generate actionable business insights.

Key Responsibilities & Contributions:

* Cleaned, transformed, and analyzed banking transaction data to identify financial patterns and trends.
* Used SQL queries, filtering, aggregations, grouping, and joins to extract meaningful insights from banking datasets.
* Developed interactive Power BI dashboards to visualize debit transactions, credit transactions, transaction volumes, and financial trends.
* Created Excel dashboards using PivotTables, charts, and interactive filters to summarize banking KPIs.
* Analyzed transaction patterns across different categories, time periods, and customer segments, where the relevant data was available.
* Monitored key financial indicators to support transaction reporting and business performance analysis.
* Compared debit and credit transactions to identify changes in transaction activity and financial patterns.
* Presented analytical findings through dashboards and reports to support data-driven decision-making.

Tools & Technologies: SQL, Microsoft Excel, Power BI, DAX, Data Cleaning, Data Visualization, Banking Analytics, Financial Data Analysis, KPI Reporting.

Project Outcome: Developed interactive financial dashboards and SQL-based analysis to improve visibility into banking transaction patterns, debit and credit activity, and financial performance.
